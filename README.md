# Flores

A minimal agent project scaffold for local experimentation.

## Features

- Simple `Agent` class with a memory buffer
- Task execution pipeline
- CLI for interactive prompting
- Test coverage for core behavior

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
python -m flores.cli
```

## Run tests

```bash
pytest -q
```
